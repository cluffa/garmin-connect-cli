# Privacy Policy — garmin-connect-cli

_Last updated: October 21, 2026_

garmin-connect-cli is a personal, non-commercial, open-source command-line
tool maintained by Alex Cluff, an individual developer. It is built for a
single user — its maintainer — to manage that user's own Garmin Connect
training data. It is not a commercial service, and it is not offered to
the public as a hosted product.

## What data the tool accesses

At the direction of the user, and only after the user authenticates with
Garmin, the tool accesses the user's own Garmin Connect data through the
Garmin Connect API, including:

- Activity data (for example, completed runs and workouts)
- Health data (for example, sleep, heart rate, and related metrics)
- Training data (structured workouts the user creates or schedules)
- Courses data (routes/courses the user creates or sends to a device)

## How the data is used

Data is used only to display, analyze, and manage the user's own training
on the user's own devices — for example, listing activities, creating
and scheduling workouts, and sending courses to the user's own Garmin
device.

## Storage and sharing

- **Local only.** The tool runs locally on the user's own computer or
  phone. Data and access tokens are stored locally on those devices.
- **No servers.** The maintainer operates no server that collects,
  receives, or stores Garmin data from any user.
- **No sale or sharing.** Data is never sold, rented, shared with third
  parties, or used for advertising.
- **No analytics or tracking.** The tool contains no analytics,
  advertising, or third-party tracking.

## Retention and deletion

Because all data is stored locally, the user can delete it at any time by
deleting the tool's local files and access tokens. The user can revoke
the tool's access at any time through their Garmin Connect account
settings.
